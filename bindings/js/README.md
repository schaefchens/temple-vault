# @schaefchens/temple

The TypeScript API of [Temple](https://github.com/schaefchens/temple-vault) – encrypted storage with plausible deniability – that its platform packages share: the types and errors, BIP-39's English wordlist (`@schaefchens/temple/words`) and a self-test (`@schaefchens/temple/self-test`). Install it with `@schaefchens/temple-react-native` or `@schaefchens/temple-web`, which bring Temple itself. Made with AI and not yet audited: see the [project's README](https://github.com/schaefchens/temple-vault#readme).
