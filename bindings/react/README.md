# @schaefchens/temple-react

React hooks for [Temple](https://github.com/schaefchens/temple-vault) – encrypted storage with plausible deniability – on React Native and the web: `TempleProvider`, `useVault` for a vault and its open space, `useQuery` and `useExecute` for queries that run again after writes.

```sh
npm install @schaefchens/temple-react
```

With `@schaefchens/temple-react-native` or `@schaefchens/temple-web`, whose `temple` goes to `TempleProvider`. Made with AI and not yet audited: see the [project's README](https://github.com/schaefchens/temple-vault#readme).
